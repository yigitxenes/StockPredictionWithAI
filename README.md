# Stock Direction & Volatility Prediction with AI Agent

A machine learning system that predicts next-day stock price direction and forward volatility, enriched with LLM-generated news sentiment features via a tool-calling agent. Built with a strong focus on data leakage prevention — walk-forward validation, look-ahead bias testing, and backtest-vs-prospective performance comparison.

## Overview

This project combines two signal sources:
- **Technical indicators** (RSI, MACD, Bollinger Bands, ATR, ADX, OBV) computed from OHLCV data via `pandas-ta`
- **News sentiment** generated by an LLM agent (Gemini) from real financial news, converted into structured numeric features

Two separate models are trained on the combined feature set:
- **Direction model** (binary classification): will the stock rise or fall next day?
- **Volatility model** (regression): what will realized volatility look like over the next N days?

## Why this project is methodologically careful

Financial time-series ML is notoriously easy to get wrong via data leakage. This project treats leakage prevention as a first-class concern, not an afterthought:

- **Chronological, walk-forward (expanding window) cross-validation** — never random split
- **Look-ahead bias testing** — automated test verifying indicators only use data available up to time *t*
- **Naive baseline comparisons** — every model result is compared against a trivial baseline (e.g. "repeat yesterday's volatility") to confirm it actually adds value
- **Backtest vs. prospective test separation** — historical sentiment backtesting (FNSPID dataset) is kept strictly separate from live/prospective sentiment testing (Finnhub API), specifically to detect LLM knowledge-cutoff leakage (see Methodology below)
- **Explicit target masking** — silent `NaN > x → False` bugs (a classic pandas footgun) are guarded against when generating labels

## Tech Stack

| Layer | Tool |
|---|---|
| Market data | `yfinance` |
| Technical indicators | `pandas-ta` |
| ML models | `xgboost`, `lightgbm` |
| Sentiment LLM | Google Gemini API (`google-genai`), tool-calling architecture |

## Key Design Decisions

- **Universe**: 11 large-cap tickers spanning tech, finance, energy, healthcare, and consumer sectors (GOOGL, NVDA, INTC, ORCL, JPM, TSLA, OXY, GILD, HD, AXP, AVGO) — selected in part for their broad coverage in the historical news dataset
- **Pooled modeling**: a single model is trained across all tickers (with ticker as a categorical feature) rather than per-ticker models, to maximize training data given the multi-year but moderate-frequency dataset
- **Sentiment backtest window**: constrained to the overlapping coverage of the FNSPID dataset across all tickers (2018-10 → 2020-06) — narrower than the main technical dataset, and treated as a separate pipeline so it doesn't compromise the main model's date range
- **Structured LLM output**: the agent never returns free text for sentiment — always a fixed JSON schema (`score`, `confidence`, `reasoning`, per-article breakdown), enabling both feature extraction and leakage auditing
